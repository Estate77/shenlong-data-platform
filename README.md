# 神龙汽车数据中台 DEMO

> Shenlong Data Platform — 纯前端数据中台演示项目，五大模块一体化集成，在线开箱即用。

**在线访问**：<https://estate77.github.io/shenlong-data-platform/>

## 项目简介

本项目将神龙汽车数据中台的五大业务模块（原 GTP-demo 独立页面）整合为一个统一的平台入口：

- **顶部一级分类**：数据管理 / 指标体系 / 营销体系 / 数据场景 / 自助分析，右上角为账户登录信息
- **左侧二级分类**：按业务域 / 能力分层分组展示，支持展开 / 收起
- **双向跟随**：顶部切换模块、左侧点击功能项、模块内部页面跳转，三者的导航高亮与面包屑实时同步
- **零删减**：所有模块内容原样保留，通过 iframe 隔离加载，互不干扰

## 技术实现

- **纯静态页面**：无构建、无后端依赖，GitHub Pages 直接托管
- **集成壳架构**：[shenlong-data-platform.html](shenlong-data-platform.html) 作为外壳，通过 iframe 加载 `GTP-demo/` 下各模块
- **postMessage 双向同步**：
  - 壳 → 模块：`{__slCmd:1, goto|fn}` 驱动页面跳转或调用模块内函数
  - 模块 → 壳：`{__sl:1, mod, page|module}` 上报当前页面（轮询侧栏 active 态）与跨模块跳转请求
  - 各模块尾部追加了一段独立同步脚本，不影响模块自身逻辑
- **样式**：集成壳采用深蓝金配色企业风格；各模块保留原有视觉风格，经 CSS 隔离互不影响

## 本地运行

无需安装任何依赖，直接双击打开 `shenlong-data-platform.html` 即可；或启动任意静态服务器：

```bash
python -m http.server 8765
# 访问 http://localhost:8765/shenlong-data-platform.html
```
